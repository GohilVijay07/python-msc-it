💡 How CRUD Works in this To-Do List Web App:

C Create (POST /add) task = Task(title, desc, priority, due_date)
db.session.add(task); db.session.commit()
R Read (GET /) Pending: Task.query.filter_by(is_completed=False)
Completed: Task.query.filter_by(is_completed=True)
U Update (GET /toggle & POST /update) task.is_completed = not task.is_completed
db.session.commit()
D Delete (POST /delete/<id>) db.session.delete(task)
db.session.commit()

Database: todo.db (SQLite) | Schema: Task (id, title, description, priority, is_completed, due_date)
